Instructions

  1. Drag the "QA Test All" button to your bookmarks bar
  2. Navigate to the Dialer page in the webportal
  3. Click the bookmarklet to run all tests
  4. Check the browser console (F12) for results

Alternative: Manual Console Test

Or copy-paste this into the console:

document.querySelectorAll('button').length - Count all buttons
document.querySelectorAll('audio').length - Count audio elements
document.querySelectorAll('[data-value]').length - Count dialpad keys
document.querySelectorAll('[data-action]').length - Count action buttons
